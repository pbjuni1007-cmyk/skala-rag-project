# 팀 Agent 통합 검증 상태

2026-10-07 기준. 통합 브랜치는 `work/agent-integration`, 검토 창구는 [Draft PR #22](https://github.com/pbjuni1007-cmyk/skala-rag-project/pull/22)다.

팀원 PR #19·#21·#18·#20을 연결하고, 공통 계약·재개·인용·출력 경계의 문제를 보완했다. 현재 저장소 검사 802개와 로컬 실행 승인 보호 검사 10개, 총 812개가 네트워크 차단 환경에서 통과했다. 실제 보고서 생성은 성공했지만 품질 평가와 최종 발행은 아직 완료되지 않았다.

| 실제 실행 | 결과 | 확인한 범위 |
| --- | --- | --- |
| main-01 | needs_attention | 인용 보정·요청 상한 실패를 보존하고 원인 수정 |
| main-02 | incomplete | 기술 조사와 도메인 평가, 실제 Supervisor의 도메인 재조사 요청. 요청 용량 한도에서 중단 |
| main-03 | incomplete | 첫 입력 토큰 계산 API 오류. 생성 요청·추가 비용 없음 |
| main-04 | incomplete | 교체한 키로 네 관점 조사와 실제 재조사 요청. 기술별 질의 수·근거 요약 범위 문제 수정 |
| main-05 | incomplete | 인용 위치 수정 중 원문 확장 거부. 같은 원문이 유일한 후보에 있을 때만 위치를 교정하도록 보완 |
| main-06 | incomplete | 네 관점과 28개 주장·72개 근거를 가진 보고서 생성. 품질 평가의 API 요청 형식 오류에서 중단 |

사용자의 키 교체 후 같은 `gpt-5.6-luna`의 조회와 실제 생성이 성공했다. 이전 키가 작동하지 않은 정확한 이유는 미확인이다. main-06은 Judge 응답 형식의 중첩 필수 필드 누락 때문에 API가 거부한 별도 코드 오류다. 필수 필드를 명시한 뒤 입력 계산 요청이 HTTP 200으로 수락됐다. 실제 평가는 아직 실행하지 않았다.

원문을 모두 포함한 현재 Judge 입력은 32,376토큰이다. 중복을 줄인 별도 시험도 24,321토큰으로 기존 24,000 한도와 수정 여유분을 넘었다. 이 시험의 입력 변환은 제품 코드에 넣지 않았다. 승인된 6개 실행 ID도 모두 사용했다. 추가 실행과 입력 한도 변경은 승인을 받은 뒤 적용한다. 실행당 전체 HTTP 100회·생성 40회·추가 비용 1만원의 기존 상한은 유지된다.

[main-06 Reference Check](reference-check-main06.md)는 모든 28개 주장, 72개 인용, 26개 공백 결정, 9개 상충 기록을 대조했다. 인용 위치는 모두 확인했지만 실험조건·성숙도·사실 분류에 수정 사항이 있어 **최종 보고서로 사용할 수 없다**. 원본은 보존하고 새 보고서에서 수정 여부를 다시 검증한다.

1차 제출 ZIP은 17:48에 만들었다. 7페이지 보고서와 실제 main-02 추적 화면 3개가 있으며, 기존 분석과 실제 부분 결과를 편집한 제출물임을 명시했다. Agent의 자동 생성·평가 통과 최종본으로 표시하지 않았다.

교수 배점표의 패턴·State 항목은 `fd8f6a6`에서 독립 검토자의 40/40 평가를 받았다. 실제 교수 점수나 전체 100점 통과를 뜻하지 않는다. 동적 동작·재현성과 평가·보고서 항목은 최종 증거로 검토해야 한다. ai-deslop은 세 관점의 코드 정리와 후속 변경 검토를 진행했고 README는 요청한 11개 항목으로 개편했다. 새 환경의 고정 의존성 설치와 핵심 검사 69개도 `fd8f6a6`에서 통과했다.

남은 순서는 추가 실행 승인 → 실제 품질 평가·재작업 완료 → 새 보고서 전수 Reference Check → 나머지 독립 채점 → 변경 범위 ai-deslop·회귀·재현 → 최종 PDF·추적 화면·ZIP 검수다. main 병합과 실제 과제 제출은 수행하지 않았다.
