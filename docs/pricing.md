# OpenAI 가격 확인

확인일: 2026-09-21. 모델 `gpt-5.6-luna`, 추론 `max`, Responses API,
Standard 처리(`service_tier=default`), 직접 OpenAI 엔드포인트를 사용한다.

공식 근거:
- https://developers.openai.com/api/docs/models/gpt-5.6-luna
- https://developers.openai.com/api/docs/pricing
- https://developers.openai.com/api/docs/guides/reasoning

100만 토큰당 일반 입력 $0.20, 출력 $1.20, 캐시 읽기 $0.02, 쓰기 $0.25다.
입력 272K 초과 시 전체 요청에 긴 문맥 단가가 적용되므로 이 앱은 입력을
24,000 이하로 제한한다. 내장 유료 검색 도구와 Fast/Batch/Flex 처리는 사용하지 않는다.
출력 사용량에는 추론 토큰도 포함된다.

장부는 캐시 할인을 제외하고 모든 입력을 $0.25로 계산하여 캐시 쓰기까지 덮는다.
이는 실제 청구액이 아닌 보수적 추정이다. 사용자 설정 환율 1,500원/USD와
비용 배수 1.10을 적용한다. 누적 내부 집행 한도 45,000원, 승인 예산 50,000원이다.
요청 전 최대 입력·출력 비용을 예약하고, 사용량 확인 후 정산한다.
시간 초과·연결 끊김·HTTP 오류는 청구 여부를 추측하지 않고 예약액을 유지한다.
모든 유료 실행은 같은 장부를 공유해야 한다. 다른 도구/계정/기기에서 쓴 비용은
이 로컬 장부로 자동 집계되지 않는다.

공식 문서의 단가와 실제 모델 조회 결과를 확인했다.
가격 확인일이 30일을 넘으면 다시 확인하기 전 생성 호출을 차단한다.

2026-09-21 실행에서 max 추론이 8,000 출력 토큰을 모두 사용하여 본문 없이 중단됐다.
사용자 지정 max는 유지하고 출력 상한 32,000, 요청 제한 300초로 조정했다.
최대 예약액은 호출당 73.26원, 실행당 40회면 2,930.40원이며 누적 내부 한도가 우선한다.
이 값은 실제 평균 비용이 아닌 최대 예약 계산이다.

후속 시장·도메인 분석에서도 32,000 토큰이 추론에 전부 사용돼 본문 없이 중단됐다.
사용자가 max 유지와 출력 한도 64,000을 명시적으로 선택했다. 이에 요청 제한은 900초로 확장했다.
새 최대 예약액은 호출당 136.62원, 40회 5,464.80원이며, 이전 사용·불확실 예약액도 계속 누적한다.
