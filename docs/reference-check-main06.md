## 새 보고서에서 반드시 수정할 내용

| 대상 | 확인된 문제 | 원문에 맞는 수정 |
| --- | --- | --- |
| `research_kivi-2`, `synthesis-1` | residual length 128에서 큰 성능 저하가 발생했다고 기술 | KIVI §4.2.3·Table 5의 저하는 **group size 128** 결과다. 바꾼 변수와 고정한 변수를 분리한다. residual length 32·96·128의 결과는 비슷하다. |
| `research_infinigen-2`, `domain-5`, `synthesis-1` | partial weight ratio 0.3의 민감도 실험에 OPT-13B 조건을 연결 | InfiniGen §6.1은 **OPT-6.7B, 입력 1,920·출력 128토큰, 배치 8, WinoGrande** 실험이다. §6.2의 OPT-13B 지연 분해와 분리한다. |
| `research_kivi-4` | 목표 기업 업무의 대표 사용조건 검증 없이 TRL 4~5로 평가 | 해당 목표 업무를 기준으로 잠정 TRL 4로 제한한다. TRL 5를 제시하려면 대표 업무·운영조건 검증 근거를 추가한다. |
| `domain-2` | 양자화 정확도 차이에서 기업 문서의 인용·사실성 검토 부담을 추론하고 `source_fact`로 표시 | 측정 결과와 업무 가설을 나누고, 업무 영향은 `team_inference`로 표시한다. |

KIVI의 근거는 [논문 v2](https://arxiv.org/abs/2402.02750v2)의 물리 7쪽 본문·9쪽 Table 5다. InfiniGen의 근거는 [논문 v1](https://arxiv.org/abs/2406.19707v1)의 물리 12~13쪽이다. 숫자의 인용 위치가 맞아도 그 숫자의 모델·설정·지표를 다른 실험과 결합하면 잘못된 주장이 된다.

추가로 다음 표현을 보완한다.

- InfiniGen의 정확도, perplexity, 지연 실험을 각각의 데이터셋·설정과 연결한다. 선행 토큰 제거 방식의 한계를 InfiniGen 자체 실패의 직접 증거로 쓰지 않는다.
- alpha 증가의 전송·지연 효과와 partial ratio 증가의 저장 오버헤드를 구분한다. KIVI residual length와 정확도도 단순한 단조 관계로 쓰지 않는다.
- CPU 캐시 보관은 생성 중의 동작이다. 요청 종료 후 장기 보존이나 타 기술보다 큰 보안 부담은 입증되지 않았다.
- 기업 운영 부담·역할별 승인 부담은 측정 결과와 가설을 구분한다. 자료에서 찾지 못한 사실은 이번 검토 범위의 미확인으로 표현한다.
- 문서 본문 해시를 저장소 커밋으로 표시하지 않는다. 실제 검토한 LongBench 문서는 [More results on LongBench](https://raw.githubusercontent.com/jy-yuan/KIVI/main/docs/long_bench.md)이며 서지 제목도 이 이름으로 고친다.

## 검증 범위와 후속 작업

웹 수집본은 2026-09-21 자료다. 이번에 공식 URL을 확인했지만 현재 페이지와 수집본의 바이트가 같다고 주장하지 않는다. PDF의 2026-10-07 조회 시각은 로컬 확인 시각이며 최초 다운로드 시각은 확인되지 않았다. 논문의 실험을 직접 재현한 검증도 아니다.
