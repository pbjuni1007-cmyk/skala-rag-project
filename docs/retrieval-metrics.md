# README 검색 지표

운영 설정은 `intfloat/multilingual-e5-small`, 300토큰 청크·50토큰 중첩, top-K=5다. 로컬 NumPy 벡터 인덱스를 사용한다.

README 수치는 [24문항 정답셋](../eval/retrieval-technical.json)과 저장된 검색 순위를 재집계한 결과다. 새 유료 호출이나 새 검색 실험을 수행한 수치가 아니다. 기존 [계산 함수](../scripts/benchmark_embeddings.py)의 적중·역순위 정의를 사용했다.

- **Hit Rate@5**: 상위 5개 청크 중 하나가 등록된 정답 구절 하나 전체를 포함한 문항 비율. 출처와 물리 페이지도 같아야 한다.
- **MRR@5**: 첫 적중 청크 순위의 역수를 문항 전체에서 평균한다. 상위 5개에 없으면 0이다.
- 모든 정답 구절의 합집합을 회수하는 `complete`와는 다른 지표다.

| 언어 | 문항 수 | Hit Rate@5 | MRR@5 |
| --- | ---: | ---: | ---: |
| 영어 | 24 | 21/24 = 87.5% | 0.619444 |
| 한국어 번역·진단 | 24 | 15/24 = 62.5% | 0.445833 |

2026-09-22 기준 결과와 2026-10-07 실제 실행 준비의 저장 순위에서 같은 값을 얻었다. 문항별 적중·역순위, 입력 파일 해시와 검색 식별값은 [재집계 기록](../eval/retrieval-readme-metrics.json)에 있다. 기준 검색 순위는 [baseline](../eval/retrieval-baseline.json)에 보존돼 있다. 실행 준비 때 생성하는 검색 회귀 기록은 영어 정답의 원문·조건 회수가 기준보다 떨어지는지를 별도로 검사한다.

현재 정답셋은 문자 위치를 확인한 `human_review_pending` 상태다. 이미 사용한 selection·holdout 질문을 함께 집계했으므로 알려진 질문의 회귀 검사다. 독립적인 일반화 성능, 모델 답변 정확도, Agent 전체 성공률로 해석하지 않는다. 과거 8문항의 페이지·키워드 적중 지표와도 섞지 않는다.
