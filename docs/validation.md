# 실행과 결과 검증

검증은 세 단계로 나눈다. 코드 테스트는 검색·호출 제한·근거 연결·출력 계약을 확인한다. 문맥 회수 진단은 실제 질문에서 필요한 원문이 모델에 전달되는지 확인한다. 보고서 생성에서는 호출 기록과 최종 문장의 출처를 함께 대조한다.

## 로컬 검증

```bash
uv sync --frozen
uv run python -m pytest -q
uv run python app.py --help
```

테스트는 API 키 없이 실행한다. 실제 보고서 생성에는 `.env.example`을 참고해 로컬 환경을 설정한다. 호출 비용은 하나의 누적 사용량 파일로 관리하며, 실패하거나 사용량이 확정되지 않은 요청도 예산에서 제외하지 않는다.

2026-09-22 보완 코드에서 테스트 312개가 통과했다. 공개 대상 코드·설정·테스트만 복사한 별도 폴더에서도 API 키 없이 동일한 312개가 통과했다.

## 확인 항목

- 기술별 주장과 시장성·이해관계자·도메인 적용 판단이 모두 결과에 포함되는지 확인한다.
- PDF 줄바꿈으로 나뉜 단어는 원문에서 대응 위치가 하나일 때만 원래 문자열로 복원한다. 숫자·문구 차이나 중복 대응은 자동 복원하지 않는다.
- 인용문을 원문 청크와 대조하고, 다른 실험의 장비·모델·입출력 길이·배치 조건이 섞이지 않았는지 검토한다.
- 검색으로 전달된 조건과 생성 문장에 실제 반영된 조건을 나누어 확인한다.
- 생성 전 토큰 제한을 검사하고, 부분 보완 후에도 전체 출력 구조와 기존 주장 보존 여부를 검증한다.
- SUMMARY가 기술 성숙도만 반복하지 않고 종합 판단과 후속 관점을 포함하는지 확인한다.

[문맥 회수 진단](context-retrieval.md)과 [검색 실험](retrieval-experiments.md)은 서로 다른 측정이다. 구절이 회수됐다는 사실만으로 최종 판단의 타당성을 보장하지 않는다. 최종 보고서의 조건 연결과 적용 판단은 원문 검토를 거쳐 확정한다.

## 최근 생성 결과

`20260922T024515-dc9b07` 실행에서 28개 주장과 92개 인용을 검증했다. 모든 본문 주장을 한 번씩 배치했고, 인용문·출처·페이지와 실행 코드 해시를 대조했다. SUMMARY는 801자다. 자동 검사 후 상태는 `human_review_pending`이며, 조건 연결과 적용 판단의 의미 검수를 남겨 둔다. [보고서](../reports/latest/report.md)와 [인용 검수표](../reports/latest/citation_review.md)를 함께 읽는다.

## 제출 편집본

공유 보고서는 위 실행 결과를 바탕으로 참고문헌 제목·사이트명을 보완하고, domain-5의 논문 결과와 업무 적용 추론을 구분했다. 반복되는 근거 공백은 본문에서 다섯 주제로 묶었으며 19개 원래 항목과 판단은 공백 검수표에 보존했다. 실행 원본과 편집본의 파일 해시는 `reports/latest/run.json`에 기록한다. 이 편집은 새로운 모델 실행이나 전체 의미 검수 완료를 뜻하지 않는다.

최신 정본과 편집본으로 설계 PDF 24페이지, 평가 PDF 10페이지를 만들었다. 설계의 Mermaid 흐름도 7개를 렌더링했으며, 긴 실행 흐름도는 단계명을 줄이고 바로 뒤에 전체 처리 내용을 표로 보존했다. 평가 PDF 첫 페이지의 SUMMARY와 적용 설명은 페이지 상단에서 361.5pt 안에 배치되어 A4 반 페이지(421.0pt) 이내다. 전체 페이지의 한글·표·페이지 경계와 본문 영역을 확인했다. 상세 검수 링크는 팀 점검용 스냅샷 저장소의 Markdown으로 연결된다.

## 실행 완료 시 Markdown·PDF 동시 출력

출력 계약 v2부터 일반 실행과 `--render`는 같은 보고서 본문에서 Markdown과 PDF를 함께 생성한다. PDF 오류는 `incomplete`로 처리하며, 재출력이 실패하면 이전 성공 검증 기록을 실패 상태로 바꾼다. 비교표·인용·해소된 공백 처리를 두 형식에서 공유하고, SUMMARY는 실제 조판 높이로 반 페이지 이내인지 검사한다. 저장된 검증 결과의 사본을 재출력해 자동 PDF 10페이지의 한글·표·장 순서를 확인했다. 새 GPT 호출은 없었다. 이 확인은 기존 실행의 모델 결과나 의미 검수 상태를 바꾸지 않는다.

이 변경의 전체 회귀 테스트는 319개가 통과했다. 폰트·PDF 쓰기 실패, 재렌더 실패 시 이전 성공 기록 무효화, 반 페이지 초과 SUMMARY, 여러 페이지의 참고문헌, 28개 주장과 인용의 보존을 확인했다.
